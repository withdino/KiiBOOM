연결 안 됨

안녕하세요 👋

KiiBOOM Cybrix 16 전용 키 설정 도구입니다. 바꾼 내용은 키보드에 바로 저장되며, 다른 맥이나 윈도우 PC에 꽂아도 그대로 유지됩니다.

  1. Cybrix 16을 USB 케이블로 컴퓨터에 연결하세요. (무선/블루투스 모드에서는 설정할 수 없어요)
  2. 아래 키보드 연결을 누르고, 뜨는 창에서 Kiiboom Cybrix 16을 선택한 뒤 연결을 누르세요.
  3. 바꾸고 싶은 키를 클릭하고, 오른쪽 목록에서 원하는 기능을 고르면 끝!
이 브라우저는 키보드 연결 기능(WebHID)을 지원하지 않아요. Google Chrome 또는 Microsoft Edge로 열어 주세요. (Safari·Firefox는 지원하지 않습니다)

조명 설정은 바꾸는 즉시 키보드에 저장됩니다.

매크로 목록

매크로

키 하나로 긴 문장을 자동으로 입력해요. 예: 이메일 주소, 자주 쓰는 인사말, 서명 등.
만든 다음 키 설정 탭에서 원하는 키에 매크로 카테고리의 이 매크로를 지정하세요.

특수 동작 넣기:
⚠️ 매크로는 영문·숫자·기호만 입력할 수 있어요. 한글은 컴퓨터의 입력기를 거쳐야 해서 키보드가 직접 입력할 수 없습니다. 매크로가 실행될 때 입력 상태가 영문이어야 정확히 입력돼요.

백업

지금 설정(모든 레이어의 키, 노브, 매크로, 조명)을 파일로 저장해 두면 언제든 되돌릴 수 있어요.

공장 초기화

키 배치와 노브 설정을 처음 샀을 때 상태로 되돌립니다. 매크로는 선택해서 함께 지울 수 있어요. 진행 전에 자동으로 백업 파일을 저장합니다.
