# Cybrix 16 맵퍼

KiiBOOM Cybrix 16(키 16개 + 노브 3개 매크로 패드) 전용 키 설정 도구입니다. 맥과 윈도우 둘 다 쓸 수 있고, VIA 사이트 없이 바로 설정할 수 있습니다.
설정은 **키보드 안에 저장**되므로, 집 맥에서 설정한 키보드를 회사 윈도우 PC에 꽂아도 그대로 동작합니다.

## 실행 방법

필요한 것: **Google Chrome** 또는 **Microsoft Edge**. Safari와 Firefox는 키보드 연결(WebHID)을 지원하지 않습니다.

| 컴퓨터 | 실행 |
|---|---|
| 맥 | `Cybrix16 맵퍼 열기 (맥).command`를 더블클릭 |
| 윈도우 | `Cybrix16 맵퍼 열기 (윈도우).bat`을 더블클릭 |

1. Cybrix 16을 **USB 케이블**로 연결합니다. 무선 모드에서는 설정할 수 없습니다.
2. **🔌 키보드 연결**을 누르고 **Kiiboom Cybrix 16**을 선택합니다.
3. 오른쪽 위에서 **🍎 맥 / 🪟 윈도우**를 고르면 단축키 목록과 표시(⌘ ↔ Ctrl/Win)가 바뀝니다.
4. 키를 클릭하고 원하는 기능을 고르면 즉시 저장됩니다.

### 윈도우 PC에서 처음 받을 때
1. GitHub 저장소에서 **Code → Download ZIP**으로 내려받아 압축을 풉니다. git이 있다면 `git clone`도 됩니다.
2. `Cybrix16 맵퍼 열기 (윈도우).bat`을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
   - 회사 보안 정책 때문에 실행되지 않으면, `index.html`을 Chrome이나 Edge 창으로 끌어다 놓아 여세요.

## 집 설정 ↔ 회사 설정 바꾸기

키보드는 설정을 한 벌만 저장합니다. 두 가지 방법이 있습니다.

- **레이어로 나누기** (추천): 예를 들어 `0 Red`는 맥용, `1 Green`은 윈도우용으로 키를 배치하고, 큰 노브를 눌러 레이어를 바꿔 씁니다.
- **백업 파일로 바꾸기**: **백업 · 초기화** 탭에서 설정을 파일(`집용.json`, `회사용.json`)로 저장해 두고, 필요할 때 **파일에서 설정 불러오기**를 합니다.

## 파일 구성

- `index.html`: 설정 도구 전체 (파일 하나)
- `Cybrix16 맵퍼 열기 (맥).command`, `Cybrix16 맵퍼 열기 (윈도우).bat`: 실행기 (localhost:8716)
- `windows/serve.ps1`: 윈도우용 작은 웹 서버 (설치 필요 없음, PowerShell 기본 기능)
- `raycast-scripts/`: 맥 Raycast용 스크립트
- `CLAUDE.md`: 키 번호와 레이어 이름 규칙, 맞춤 설정 기록
